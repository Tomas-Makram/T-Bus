# 📌 Overview

TBus is a comprehensive transportation management system developed to help transportation companies efficiently manage:

* Fleet Operations
* Driver Accounts
* Daily Trips
* Revenue Collection
* Expenses Tracking
* Driver Settlements
* Financial Reporting

The platform centralizes all transportation activities into one modern dashboard, providing full visibility over operational and financial performance.

---

# ✨ Key Features

## 🚍 Fleet Management

Manage all company buses from a single interface.

### Capabilities

* Add/Edit/Delete buses
* License plate tracking
* Bus assignment to trips
* Operational history monitoring

---

## 👨‍✈️ Driver Management

Maintain complete driver records.

### Includes

* Driver profiles
* National ID tracking
* Multiple phone numbers
* Driver performance monitoring
* Driver account integration

---

## 🗺️ Trip Management

Full lifecycle management of transportation trips.

### Features

* Create trips
* Edit trips
* Trip settlement workflow
* Route management
* Departure and destination tracking
* Trip ownership classification
* Company trip handling
* Historical trip archive

# 🔧 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/TBus.git
```

## Restore Packages

```bash
dotnet restore
```

## Configure Database

Update:

```json
appsettings.json
```

Connection String:

```json
"ConnectionStrings": {
  "Connection": "YOUR_CONNECTION_STRING"
}
```

## Run Application

```bash
dotnet run
```
